## Aperçu

Annuler une résiliation planifiée

Retire une résiliation planifiée en fin de période (`cancel_at_period_end`).


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `POST /subscriptions/&#123;id&#125;/resume` (Annuler une résiliation planifiée).



### Voir aussi

[Cancel subscription](/api/subscriptions/SubscriptionsController_cancel)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /subscriptions/{id}/resume`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | UUID de l’abonnement |

### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

_Pas de corps JSON pour cette opération._


## Réponses

| Statut | Description |
| --- | --- |
| `200` | - |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/subscriptions/value/resume" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```
