## Aperçu

Get checkout settings

Langue, URLs, bouton, frais, analytics, champs custom.

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /settings/checkout`.

## Authentication

Les routes marchandes exigent une clé API dans `X-API-KEY` (voir [Aperçu](/api)). Clé **test** sur `https://sandbox.api.lomi.africa`, clé **live** sur `https://api.lomi.africa`.

## Endpoint

`GET /settings/checkout`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Example

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/settings/checkout" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
