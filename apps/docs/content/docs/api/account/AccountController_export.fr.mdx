## Aperçu

Export account data

Bundle GDPR pour l’organisation courante. Pas de confirmation.

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `POST /account/export`.

## Authentication

Les routes marchandes exigent une clé API dans `X-API-KEY` (voir [Aperçu](/api)). Clé **test** sur `https://sandbox.api.lomi.africa`, clé **live** sur `https://api.lomi.africa`.

## Endpoint

`POST /account/export`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Example

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/account/export" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.
