## Aperçu

Delete merchant account

Preview + confirmation_token puis soft_delete_merchant.

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `POST /account/delete`.

## Authentication

Les routes marchandes exigent une clé API dans `X-API-KEY` (voir [Aperçu](/api)). Clé **test** sur `https://sandbox.api.lomi.africa`, clé **live** sur `https://api.lomi.africa`.

## Endpoint

`POST /account/delete`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Example

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/account/delete" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```
