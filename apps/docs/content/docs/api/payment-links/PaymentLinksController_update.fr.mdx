## Aperçu

Update payment link

Titre, URLs, champs checkout, expiration, ou montant.

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `PATCH /payment-links/{id}`.

## Authentication

Les routes marchandes exigent une clé API dans `X-API-KEY` (voir [Aperçu](/api)). Clé **test** sur `https://sandbox.api.lomi.africa`, clé **live** sur `https://api.lomi.africa`.

## Endpoint

`PATCH /payment-links/{id}`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Example

```bash
curl -sS -X PATCH "https://sandbox.api.lomi.africa/payment-links/ID" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```
