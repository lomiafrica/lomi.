## Aperçu

Créer un lien de paiement

Crée un lien de paiement partageable : produit (lien produit) ou montant fixe (lien instantané). Les liens produit référencent un produit et un prix optionnel ; les liens instantanés ont un montant fixe. Passez single_use à true pour éteindre le lien après le premier paiement terminé.


### Quand l’utiliser

Utilisez pour factures, vente sociale ou pages de paiement légères sans checkout complet.

### Voir aussi

[Lister les liens de paiement](/api/payment-links/PaymentLinksController_findAll) · [Sessions checkout](/api/checkout-sessions/CheckoutSessionsController_create)


## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /payment-links`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

Corps JSON.

Schéma: `object`

| Champ | Obligatoire | Type | Description |
| --- | --- | --- | --- |
| `link_type` | Oui | `enum ("product", "instant")` | - |
| `title` | Oui | `string` | - |
| `currency_code` | Oui | `enum ("XOF", "USD", "EUR")` | - |
| `description` | Non | `string` | - |
| `amount` | Non | `number` | - |
| `product_id` | Non | `string` | - |
| `price_id` | Non | `string` | - |
| `allow_coupon_code` | Non | `boolean` | - |
| `single_use` | Non | `boolean` | Quand c'est true, le lien s'éteint après le premier paiement terminé. Omettez-le pour garder le lien ouvert. |
| `allow_quantity` | Non | `boolean` | - |
| `require_billing_address` | Non | `boolean` | When true, show and require billing address on checkout. Default false when unset. |
| `require_email` | Non | `boolean` | When true, show and require customer email. Default true when unset. |
| `require_phone` | Non | `boolean` | When true, show and require customer phone. Default true when unset. |
| `require_name` | Non | `boolean` | When true, show and require customer name. Default true when unset. |
| `fields` | Non | `array<object>` | Optional ordered checkout field schema. When provided, overrides require_* booleans. |
| `expires_at` | Non | `string` | - |
| `success_url` | Non | `string` | - |
| `cancel_url` | Non | `string` | - |
| `metadata` | Non | `object` | - |

Exemple de corps :

```json
{
  "link_type": "product",
  "title": "string",
  "currency_code": "XOF"
}
```


## Réponses

| Statut | Description |
| --- | --- |
| `201` | Lien de paiement créé avec succès |
| `400` | Entrée invalide ou erreur de validation |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/payment-links" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"link_type":"product","title":"string","currency_code":"XOF"}'
```
