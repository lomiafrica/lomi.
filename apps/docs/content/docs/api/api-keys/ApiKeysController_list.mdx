## Overview

List API keys

Returns key name, type, prefix/last4, and status. Secret values are never returned.


### When to use this

Use this endpoint when your flow needs `GET /api-keys` (List API keys).


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`GET /api-keys`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Errors

Errors follow the standard JSON error format (status code and machine-readable message). Validate inputs before calling; **401** indicates a missing/invalid key, **404** a missing resource for this organization, **429** rate limiting. For safe retries on create-style calls, send an idempotency key when your flow supports it.
