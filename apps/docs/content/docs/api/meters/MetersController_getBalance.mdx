## Overview

Get meter balance for a customer

Returns units credited, units consumed, and units still available for a customer on a meter. balance is credited_units minus consumed_units.


### When to use this

Use to show remaining pack units, or before you accept more usage.

### See also

[Record usage event](/api/usage/UsageEventsController_ingest) · [Usage billing guide](/build/billing/usage-billing)
