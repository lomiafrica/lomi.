## Overview

Invite team member

Envoie une invitation. L’humain accepte dans le navigateur.

### When to use this

Use this endpoint when your flow needs `POST /team/invitations`.

## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.
