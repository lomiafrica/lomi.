## Aperçu

Update member role

Admin/Member ou role_id.

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `PATCH /team/members/{memberId}`.

## Authentication

Les routes marchandes exigent une clé API dans `X-API-KEY` (voir [Aperçu](/api)). Clé **test** sur `https://sandbox.api.lomi.africa`, clé **live** sur `https://api.lomi.africa`.

## Endpoint

`PATCH /team/members/{memberId}`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Example

```bash
curl -sS -X PATCH "https://sandbox.api.lomi.africa/team/members/ID" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
```
