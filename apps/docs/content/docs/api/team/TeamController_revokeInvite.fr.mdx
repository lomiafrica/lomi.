## Aperçu

Revoke invitation

Annule une invitation en attente.

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `DELETE /team/invitations`.

## Authentication

Les routes marchandes exigent une clé API dans `X-API-KEY` (voir [Aperçu](/api)). Clé **test** sur `https://sandbox.api.lomi.africa`, clé **live** sur `https://api.lomi.africa`.

## Endpoint

`DELETE /team/invitations`

Base URLs:

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Example

```bash
curl -sS -X DELETE "https://sandbox.api.lomi.africa/team/invitations" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
