## Aperçu

Indicateurs de l'organisation

Renvoie le MRR, l'ARR, la LTV, le chiffre d'affaires et le nombre de clients pour votre organisation.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /organizations/metrics` (Indicateurs de l'organisation).



### Voir aussi

[Organizations guide](/build/platform/organizations) · [Merchant MRR](/api/merchants/MerchantsController_getMrr)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /organizations/metrics`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | Indicateurs de l'organisation |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/organizations/metrics" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
