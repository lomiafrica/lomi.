## Aperçu

Organisation par ID

Renvoie les détails d'une organisation par son identifiant (doit correspondre à l'organisation authentifiée)


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /organizations/&#123;id&#125;` (Organisation par ID).



### Voir aussi

[List organizations](/api/organizations/OrganizationsController_findAll)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /organizations/{id}`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | L'organisation |
| `404` | Organisation introuvable ou accès refusé |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/organizations/id_value" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
