La référence API documente l’API marchande publique : les endpoints qu’un développeur doit utiliser depuis une intégration serveur. Elle n’expose volontairement pas les services internes de providers, organisations, administration marchande ou agents.

Si vous choisissez encore votre chemin d’intégration, commencez par [Parcours d’intégration](/start/integration-journey) ou [Quelle intégration choisir ?](/build/choose-integration).

| Environnement | URL de base | Clé secrète |
| --- | --- | --- |
| Test | `https://sandbox.api.lomi.africa` | `lomi_sk_test_...` |

## Conventions de référence

- Les guides expliquent les décisions produit et les flux complets.
- Les pages API décrivent les opérations HTTP exactes.
- Les encaissements directs sont avancés ; le checkout hébergé reste la recommandation par défaut.
- Utilisez la sandbox pour développer et le live seulement après [Que vérifier avant le live ?](/start/go-live).

## Règles de contrat

- **Montants :** les champs `amount` publics sont des entiers en unités mineures. `10000` vaut 10 000 XOF, ou 100,00 USD/EUR. Envoyez toujours `currency_code`.
- **Idempotence :** `Idempotency-Key` est obligatoire sur `POST /payment-requests`, `POST /refunds`, `POST /payouts`, `POST /settlements/instant` et `POST /charge/*`. Il est optionnel sur `POST /checkout-sessions`. Voir [Clés d’idempotence](/build/reliability/idempotency-keys).
- **Listes :** interrogez avec `cursor` et `limit` (défaut 20, max 100). Réponse `{ object: "list", data, has_more, next_cursor, limit }`.
- **Erreurs :** `{ error: { code, message, details }, request_id }`. Voir [Gestion des erreurs](/api/errors).
- **Limites :** les réponses réussies incluent `X-RateLimit-Remaining` et les en-têtes IETF `RateLimit` / `RateLimit-Policy`. Un `429` inclut `Retry-After`.
- Les routes restent sans version. La `info.version` OpenAPI est la version du schéma. Envoyez `Lomi-Version` pour figer un schéma connu.

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.
