## Aperçu

Créer un produit

Crée un produit avec un ou plusieurs tarifs en une seule requête. Au moins un prix est requis. Le premier prix, ou celui avec `is_default`, est utilisé lorsque aucun prix n'est précisé au paiement. Pour un produit à l'usage, le montant du tarif est le prix du pack et `included_units` est le nombre d'unités que ce paiement achète.


### Quand l’utiliser

Utilisez lors de l’onboarding catalogue pour checkout, abonnements ou liens de paiement liés à des SKU.

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /products`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._


### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

Corps JSON.

Schéma : `CreateProductDto`

| Champ | Obligatoire | Type | Description |
| --- | --- | --- | --- |
| `name` | Oui | `string` | Nom du produit |
| `product_type` | Oui | `string` | `one_time`, `recurring` ou `usage_based` |
| `prices` | Oui | `array` | Au moins un tarif. `amount` est ce que le client paie. Pour un produit à l’usage, `included_units` est le nombre d’unités que ce paiement achète. |
| `usage_unit` | Non | `string` | Libellé de l’unité sur un produit à l’usage |
| `meter_code` | Non | `string` | Nom du compteur. Par défaut, un slug du nom du produit. |

Exemple de corps :

```json
{
  "name": "Appels API",
  "product_type": "usage_based",
  "usage_unit": "appel",
  "prices": [
    { "amount": 5000, "currency_code": "XOF", "included_units": 1000 }
  ]
}
```


## Réponses

| Statut | Description |
| --- | --- |
| `201` | Produit créé avec succès |
| `400` | Entrée invalide ou erreur de validation |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/products" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Appels API","product_type":"usage_based","usage_unit":"appel","prices":[{"amount":5000,"currency_code":"XOF","included_units":1000}]}'
```
