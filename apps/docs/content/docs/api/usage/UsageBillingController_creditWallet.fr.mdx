## Aperçu

Credit prepaid usage units to a customer meter wallet

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `POST /usage/credits` (Credit prepaid usage units to a customer meter wallet).



### Voir aussi

[Get meter balance](/api/meters/MetersController_getBalance) · [Record usage event](/api/usage/UsageEventsController_ingest)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /usage/credits`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`
