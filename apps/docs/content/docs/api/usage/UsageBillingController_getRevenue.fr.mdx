## Aperçu

Combined MRR + usage + one-time revenue metrics

### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /usage/revenue` (Combined MRR + usage + one-time revenue metrics).




### À savoir

Exige les paramètres de requête `start_date` et `end_date`.

### Voir aussi

[Organization metrics](/api/organizations/OrganizationsController_getMetrics) · [Usage billing guide](/build/billing/usage-billing)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /usage/revenue`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._

| Nom | Emplacement | Obligatoire | Schéma | Description |

| `end_date` | query | Oui | - |  |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/usage/revenue?end_date=value&start_date=value" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
