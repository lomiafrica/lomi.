## Aperçu

Create a usage subscription

Enrolls a customer on a usage_based product without an upfront charge. Required before billing metered usage.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `POST /usage/subscriptions` (Create a usage subscription).



### Voir aussi

[Usage billing guide](/build/billing/usage-billing) · [Products guide](/build/billing/products) · [Subscription usage](/api/subscriptions/SubscriptionsController_getUsage)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /usage/subscriptions`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.
