## Overview

Invoice PDF

Returns a hosted invoice URL and a download_url for the PDF. Send download_url to the human, or save the file locally from stdio MCP / the CLI.


### When to use this

Use this endpoint when your flow needs `GET /invoices/&#123;id&#125;/pdf` (Invoice PDF).


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.
