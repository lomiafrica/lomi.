## Aperçu

Get merchant details

Returns merchant profile and metrics (MRR, ARR, predicted per-customer LTV) for the organization linked to the API key. Metrics are refreshed daily and on subscription changes.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /merchants/&#123;id&#125;` (Get merchant details).



### Voir aussi

[Organizations](/build/platform/organizations) · [Merchant ARR](/api/merchants/MerchantsController_getArr)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /merchants/{id}`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | Merchant UUID |

### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | - |
| `403` | Merchant ID mismatch |
| `404` | Merchant not found |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/merchants/value" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
