## Aperçu

Débloquer un client

Retire le téléphone, l’e-mail et les empreintes de cartes de ce client de la liste de blocage Radar de l’organisation.


### Quand l’utiliser

Utilisez après un blocage par erreur, ou lorsque vous acceptez à nouveau ce client.


### Voir aussi

[Bloquer un client](/api/customers/CustomersController_block) · [lomi. Radar](/build/money/radar)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /customers/{id}/unblock`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Succès |

## Erreurs

Les erreurs suivent le format JSON standard. **401** : clé manquante ou invalide. **404** : ressource absente pour cette organisation.
