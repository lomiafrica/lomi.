## Aperçu

Bloquer un client

Ajoute le téléphone, l’e-mail et les empreintes de cartes enregistrées de ce client à la liste de blocage Radar de l’organisation. Les encaissements correspondants sont refusés tant que Radar est actif.


### Quand l’utiliser

Utilisez lorsque ce client ne doit plus payer. Inversez avec Débloquer. Tableau de bord : fiche client ou C’était de la fraude.


### Voir aussi

[Débloquer un client](/api/customers/CustomersController_unblock) · [lomi. Radar](/build/money/radar)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

`POST /customers/{id}/block`

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Succès |
| `400` | Aucun téléphone, e-mail ou carte à bloquer |
| `401` | Clé API invalide ou manquante |
| `404` | Ressource introuvable |

## Erreurs

Les erreurs suivent le format JSON standard. **401** : clé manquante ou invalide. **404** : ressource absente pour cette organisation.
