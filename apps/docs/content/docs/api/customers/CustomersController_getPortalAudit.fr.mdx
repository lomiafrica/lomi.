## Aperçu

Hosted customer portal audit

Liste les évènements portal (sessions, OTP, souscriptions self-service) pour ce client.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /customers/&#123;id&#125;/portal-audit` (Hosted customer portal audit).



### Voir aussi

[Create portal session](/api/customers/CustomersController_createPortalSession)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /customers/{id}/portal-audit`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | UUID du client |

### Paramètres de requête

| Nom | Emplacement | Obligatoire | Schéma | Description |
| --- | --- | --- | --- | --- |
| `eventType` | query | Non | - | Filtre sur customer_portal_audit_events.event_type |
| `pageSize` | query | Non | - |  |
| `page` | query | Non | - |  |



## Réponses

| Statut | Description |
| --- | --- |
| `200` | Chronologie paginée des évènements portal |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/customers/value/portal-audit?eventType=value&pageSize=1" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
