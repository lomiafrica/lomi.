## Aperçu

Créer une session de lancement du portail client

Génère un lien hébergé à usage unique vers le portail client pour un client de votre organisation. Destiné aux applications marchandes (backend) via clé API.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `POST /customers/&#123;id&#125;/portal` (Créer une session de lancement du portail client).



### Voir aussi

[Portal audit log](/api/customers/CustomersController_getPortalAudit) · [List subscriptions](/api/subscriptions/SubscriptionsController_findAll)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /customers/{id}/portal`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | UUID du client |

### Paramètres de requête

_Aucun paramètre de requête._


### Corps de la requête

Corps JSON.

Schéma: `object`

| Champ | Obligatoire | Type | Description |
| --- | --- | --- | --- |
| `return_url` | Non | `string` | - |
| `flow_type` | Non | `enum ("portal_home", "subscription_cancel", "subscription_manage")` | - |
| `flow_subscription_id` | Non | `string` | - |
| `flow_after_completion_url` | Non | `string` | - |

Exemple de corps :

```json
{
  "return_url": "string",
  "flow_type": "portal_home",
  "flow_subscription_id": "string"
}
```


## Réponses

| Statut | Description |
| --- | --- |
| `201` | Session de lancement créée |
| `401` | Clé API invalide ou manquante |
| `404` | Client introuvable ou accès refusé |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/customers/value/portal" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"return_url":"string","flow_type":"portal_home","flow_subscription_id":"string"}'
```
