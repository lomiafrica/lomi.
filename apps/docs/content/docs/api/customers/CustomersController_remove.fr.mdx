## Aperçu

Supprimer un client

Retire un client de l'usage actif : il n'apparaît plus dans les listes ni les réponses de détail. Réponse 404 si le client n'existe pas ou n'est pas accessible avec cette clé API.


### Quand l’utiliser

Utilisez pour retirer un client du répertoire lorsque la conformité ou le support l’exige.

### À savoir

La suppression peut être soumise à des contraintes de données liées ; vérifiez les réponses d’erreur métier.

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`DELETE /customers/{id}`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | UUID du client |

### Paramètres de requête

_Aucun paramètre de requête._




## Réponses

| Statut | Description |
| --- | --- |
| `200` | Client supprimé avec succès |
| `401` | Clé API invalide ou manquante |
| `404` | Client introuvable ou accès refusé |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X DELETE "https://sandbox.api.lomi.africa/customers/value" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
