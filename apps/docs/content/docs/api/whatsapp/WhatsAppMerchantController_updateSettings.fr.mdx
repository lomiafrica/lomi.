## Aperçu

Règle `inbound_payment_link` sur `off`, `keyword` ou `any`. Connectez WhatsApp d'abord.

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`PATCH /whatsapp`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d'URL

_Aucun paramètre d'URL._

### Paramètres de requête

_Aucun paramètre de requête._

### Corps

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `inbound_payment_link` | Oui | `off` \| `keyword` \| `any` | Quand un texte reçu reçoit un lien de paiement. |

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Réglage de réponse mis à jour |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **400** : `inbound_payment_link` manquant ou hors de `off`, `keyword`, `any`.

## Exemple

```bash
curl -sS -X PATCH "https://sandbox.api.lomi.africa/whatsapp" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inbound_payment_link":"keyword"}'
```
