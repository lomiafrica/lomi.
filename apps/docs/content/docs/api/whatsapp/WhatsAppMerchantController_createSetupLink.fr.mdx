## Aperçu

Renvoie une `url`. Le marchand l'ouvre sur son téléphone et termine l'inscription Meta.

`connection_type` vaut `coexistence` par défaut : l'application WhatsApp Business reste sur le téléphone. `dedicated` est un numéro réservé à l'API.

La première connexion demande environ 150 000 F CFA de volume mensuel. Un numéro déjà connecté peut redemander un lien en dessous de ce seuil.

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /whatsapp/setup-links`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d'URL

_Aucun paramètre d'URL._

### Paramètres de requête

_Aucun paramètre de requête._

### Corps

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `connection_type` | Non | `coexistence` \| `dedicated` | `coexistence` par défaut. |
| `language` | Non | string | Langue du parcours de connexion. |

## Réponses

| Statut | Description |
| --- | --- |
| `200` | `url` à ouvrir sur le téléphone du marchand |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. La première connexion peut être refusée tant que le volume mensuel n'atteint pas environ 150 000 F CFA.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/whatsapp/setup-links" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"connection_type":"coexistence"}'
```
