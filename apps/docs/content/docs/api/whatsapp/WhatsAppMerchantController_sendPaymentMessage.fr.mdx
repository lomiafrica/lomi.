## Aperçu

Envoie un lien `pay.lomi.africa` à `to` sur le numéro connecté. L'envoi utilise un modèle approuvé : le client n'a pas besoin d'avoir écrit en premier.

Passez `amount` en unités mineures, ou `checkout_session_id` (UUID) pour un paiement déjà créé. `Idempotency-Key` est optionnel quand un paiement est créé.

Quand le client écrit au numéro, lomi. peut aussi répondre dans la conversation avec un bouton de paiement. Ce réglage est `inbound_payment_link` sur `GET /whatsapp`.

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`POST /whatsapp/payment-messages`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d'URL

_Aucun paramètre d'URL._

### Paramètres de requête

_Aucun paramètre de requête._

### En-têtes

| Nom | Emplacement | Obligatoire | Schéma | Description |
| --- | --- | --- | --- | --- |
| `Idempotency-Key` | header | Non | string | Une reprise renvoie la réponse d'origine quand un paiement est créé. |

### Corps

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `to` | Oui | string | Numéro WhatsApp du client. |
| `amount` | Non | integer | Montant en unités mineures. |
| `currency_code` | Non | `XOF` \| `USD` \| `EUR` | Devise du paiement. |
| `title` | Non | string | Libellé du lien. |
| `checkout_session_id` | Non | uuid | Paiement déjà créé, à envoyer tel quel. |

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Lien envoyé sur le numéro connecté |
| `401` | Clé API invalide ou manquante |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **400** : `to` manquant, ou ni `amount` ni `checkout_session_id` ne permettent de construire un lien.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/whatsapp/payment-messages" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to":"+2250100000000","amount":1500,"currency_code":"XOF"}'
```
