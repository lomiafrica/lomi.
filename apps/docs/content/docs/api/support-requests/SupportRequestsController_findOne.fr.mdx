## Aperçu

Obtenir une demande d'assistance

### Quand l'utiliser

Utilisez cet endpoint pour relire un ticket à partir de son identifiant.

## Authentification

Les routes marchandes exigent une clé API dans l'en-tête `X-API-KEY`.

## Endpoint

`GET /support-requests/{id}`

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Succès |
| `404` | Introuvable |

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._

### Paramètres de requête

_Aucun paramètre de requête._

### En-têtes

| Nom | Emplacement | Obligatoire | Schéma | Description |
| --- | --- | --- | --- | --- |
| `Lomi-Version` | header | Non | - | Optional schema version pin. Echoes OpenAPI info.version (currently 1.2.0). Routes stay unversioned. |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/support-requests/$TICKET_ID" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
