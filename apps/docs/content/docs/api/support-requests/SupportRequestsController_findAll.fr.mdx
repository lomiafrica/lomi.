## Aperçu

Lister les demandes d'assistance

### Quand l'utiliser

Utilisez cet endpoint pour suivre les tickets ouverts depuis le tableau de bord ou le MCP.

## Authentification

Les routes marchandes exigent une clé API dans l'en-tête `X-API-KEY`.

## Endpoint

`GET /support-requests`

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Succès |
