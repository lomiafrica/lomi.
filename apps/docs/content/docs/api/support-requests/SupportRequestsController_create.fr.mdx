## Aperçu

Créer une demande d'assistance

Ouvre un ticket dans Paramètres → Assistance. L'équipe lomi. le voit dans la console admin et envoie une confirmation.

### Quand l'utiliser

Utilisez cet endpoint pour déposer une plainte ou demander de l'aide sur un compte marchand.

## Authentification

Les routes marchandes exigent une clé API dans l'en-tête `X-API-KEY` (voir [Aperçu](/api)). Clé **test** contre `https://sandbox.api.lomi.africa`, clé **live** contre `https://api.lomi.africa`.

## Endpoint

`POST /support-requests`

## Réponses

| Statut | Description |
| --- | --- |
| `201` | Demande créée |

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._

### Paramètres de requête

_Aucun paramètre de requête._

### En-têtes

| Nom | Emplacement | Obligatoire | Schéma | Description |
| --- | --- | --- | --- | --- |
| `Lomi-Version` | header | Non | - | Optional schema version pin. Echoes OpenAPI info.version (currently 1.2.0). Routes stay unversioned. |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/support-requests" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"category":"technical","message":"Les sessions checkout restent ouvertes après un paiement Wave.","subject":"Wave checkout bloqué"}'
```
