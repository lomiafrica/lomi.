## Overview

Chaque ligne est un bureau : vendus, restants, scannés, et les derniers acheteurs.

## Authentication

Merchant routes require an API key in the `X-API-KEY` header. Use a test key against `https://sandbox.api.lomi.africa` and a live key against `https://api.lomi.africa`.

## Endpoint

`GET /events`

## Requête

Aucun paramètre de chemin, paramètre de requête, ni corps.

## Responses

| Status | Description |
| --- | --- |
| `200` | Success |
| `403` | Ticketing is off |

## Erreurs

**403** : Ticketing est désactivé. **401** : clé manquante ou invalide. **429** : trop de requêtes.

## Example

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/events" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
