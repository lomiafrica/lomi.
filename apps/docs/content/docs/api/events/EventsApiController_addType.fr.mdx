## Overview

Ajoute un billet ou un pack. seats est le nombre de QR qu'une vente émet. capacity est le nombre de ce type qui peut être vendu. Ticketing doit être activé.

## Authentication

Merchant routes require an API key in the `X-API-KEY` header. Use a test key against `https://sandbox.api.lomi.africa` and a live key against `https://api.lomi.africa`.

## Endpoint

`POST /events/{id}/types`

## Requête

### Paramètres de chemin

| Nom | Requis | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | `string` | Identifiant de l'événement |

### Corps

`seats` est le nombre de QR qu'une vente émet. `capacity` est le nombre de ce type qui peut être vendu.

| Champ | Requis | Type | Description |
| --- | --- | --- | --- |
| `name` | Oui | `string` | - |
| `price_amount` | Oui | `integer` | - |
| `capacity` | Oui | `integer` | - |
| `currency` | Non | `string` | - |
| `seats` | Non | `integer` | - |

## Responses

| Status | Description |
| --- | --- |
| `200` | Success |
| `403` | Ticketing is off |

## Erreurs

**403** : Ticketing est désactivé. **401** : clé manquante ou invalide. **404** : cet événement n'est pas dans l'organisation. **429** : trop de requêtes.

## Exemple

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/events/evt_EXAMPLE/types" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"General","price_amount":5000,"capacity":100}'
```
