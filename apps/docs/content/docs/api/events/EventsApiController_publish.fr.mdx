## Overview

Ticketing doit être activé. Omettez published ou envoyez true pour publier. Envoyez false pour retirer la page.

## Authentication

Merchant routes require an API key in the `X-API-KEY` header. Use a test key against `https://sandbox.api.lomi.africa` and a live key against `https://api.lomi.africa`.

## Endpoint

`POST /events/{id}/publish`

## Requête

### Paramètres de chemin

| Nom | Requis | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | `string` | Identifiant de l'événement |

### Corps

Omettez le corps, ou envoyez `published: true`, pour publier. Envoyez `published: false` pour retirer la page.

| Champ | Requis | Type | Description |
| --- | --- | --- | --- |
| `published` | Non | `boolean` | - |

## Responses

| Status | Description |
| --- | --- |
| `200` | Success |
| `403` | Ticketing is off |

## Erreurs

**403** : Ticketing est désactivé. **401** : clé manquante ou invalide. **404** : cet événement n'est pas dans l'organisation. **429** : trop de requêtes.

## Example

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/events/evt_EXAMPLE/publish" \
  -H "X-API-KEY: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: evt-1"
```
