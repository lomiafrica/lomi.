## Aperçu

List settlement periods

Returns completed payment totals grouped by availability date and currency. Each settlement_id is &#123;currency&#125;:&#123;YYYY-MM-DD&#125; (UTC date of available_at).


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /settlements` (List settlement periods).



### Voir aussi

[List settlement transactions](/api/settlements/SettlementsController_findTransactions)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /settlements`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

_Pas d’autre paramètre dans l’URL._

## Réponses

| Statut | Description |
| --- | --- |
| `200` | Settlement periods |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/settlements?pageSize=1&page=1" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
