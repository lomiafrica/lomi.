## Aperçu

List transactions in a settlement period

Returns completed transactions whose available_at falls on the settlement date for the given currency.


### Quand l’utiliser

Utilisez cet endpoint quand vous devez exécuter `GET /settlements/&#123;id&#125;/transactions` (List transactions in a settlement period).



### Voir aussi

[List settlement periods](/api/settlements/SettlementsController_findAll)

## Authentification

Les routes marchandes nécessitent une clé API dans l’en-tête `X-API-KEY` (voir [Vue d’ensemble](/api)). Utilisez une clé **test** avec `https://sandbox.api.lomi.africa` et une clé **live** avec `https://api.lomi.africa`.

## Endpoint

`GET /settlements/{id}/transactions`

URLs de base :

- `https://sandbox.api.lomi.africa`
- `https://api.lomi.africa`

## Requête

### Paramètres d’URL

| Nom | Obligatoire | Schéma | Description |
| --- | --- | --- | --- |
| `id` | Oui | - | Settlement id, format &#123;currency&#125;:&#123;YYYY-MM-DD&#125; |

### Paramètres de requête

| Nom | Emplacement | Obligatoire | Schéma | Description |
| --- | --- | --- | --- | --- |
| `pageSize` | query | Non | - |  |
| `page` | query | Non | - |  |



## Réponses

| Statut | Description |
| --- | --- |
| `200` | Transactions in settlement |

## Erreurs

Les erreurs suivent un format JSON standard. **401** : clé manquante ou invalide. **404** : ressource introuvable. **429** : trop de requêtes. Pour les créations, envoyez une clé d’idempotence si votre flux le permet.

## Exemple

```bash
curl -sS -X GET "https://sandbox.api.lomi.africa/settlements/value/transactions?pageSize=1&page=1" \
  -H "X-API-KEY: $LOMI_SECRET_KEY"
```
