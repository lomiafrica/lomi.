## Overview

Create a bank top-up

Create a bank-transfer top-up and return the wire instructions and reference code. The balance is credited when the wire is confirmed.


### When to use this

Use this endpoint when your flow needs `POST /top-ups` (Create a bank top-up).


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.

## Endpoint

`POST /top-ups`

Base URLs:
