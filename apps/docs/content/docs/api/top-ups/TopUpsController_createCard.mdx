## Overview

Create a card top-up

Create a card top-up and return a hosted checkout URL. The credited amount is the requested amount; the real card cost is charged on top, never less. The card payment webhook credits the balance on payment success.


### When to use this

Use this endpoint when your flow needs `POST /top-ups/card` (Create a card top-up).


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.
