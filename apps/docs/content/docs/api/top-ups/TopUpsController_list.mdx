## Overview

List balance top-ups

List balance top-up requests (bank and card channels) for the request organization.


### When to use this

Use this endpoint when your flow needs `GET /top-ups` (List balance top-ups).


## Authentication

Merchant routes require an API key in the `X-API-KEY` header (see [Overview](/api)). Use a **test** key against `https://sandbox.api.lomi.africa` and a **live** key against `https://api.lomi.africa`.
