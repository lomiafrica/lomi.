---
title: 'Comment tester un paiement ?'
description: 'Créez une session de checkout en sandbox, ouvrez l’URL hébergée, payez avec un moyen de test et vérifiez le résultat.'
---

C’est le chemin le plus rapide pour vérifier que votre compte lomi., votre clé API, le checkout et vos hypothèses webhook fonctionnent ensemble.

## Avant de commencer

Il vous faut :

- Un compte lomi.
- Accès CLI via `lomi login`, ou une clé secrète de test comme `lomi_sk_test_...`.
- Une URL de succès et une URL d’annulation, locales ou hébergées.

## Option A : CLI (recommandé)

### 1. Installer et se connecter

```bash filename="Terminal"
npm install -g lomi.cli
lomi login
lomi quickstart
```

### 2. Créer une session de checkout

Mode interactif :

```bash filename="Terminal"
lomi checkout create
```

Sans interaction (scripts et agents) :

```bash filename="Terminal"
lomi checkout create \
  --amount 10000 \
  --currency XOF \
  --success-url https://example.com/success \
  --cancel-url https://example.com/cancel \
  --json
```

Ouvrez le `checkout_url` de la sortie dans le navigateur.

### 3. Relayer les webhooks (optionnel)

```bash filename="Terminal"
lomi listen http://localhost:3000/webhooks
```

Voir [Démarrer avec le CLI](/start/cli-quickstart) pour le parcours terminal complet.

## Option B : cURL

### 1. Créer une session de checkout

```bash
curl -sS -X POST "https://sandbox.api.lomi.africa/checkout-sessions" \
  -H "X-API-Key: $LOMI_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 10000,
    "currency_code": "XOF",
    "title": "Commande de test",
    "success_url": "https://example.com/success",
    "cancel_url": "https://example.com/cancel"
  }'
```

La réponse contient une URL de checkout hébergé. Ouvrez-la dans votre navigateur.

## Option C : SDK

Créez le même checkout sandbox depuis votre code avec `@lomi./sdk`. Installation, premier appel, checkout et vérification de webhook : [Démarrer avec le SDK](/start/sdk-quickstart). Autres langages : [Python](/build/sdks/python), [Go](/build/sdks/go), [PHP](/build/sdks/php).

## Option D : MCP

Demandez à Cursor, Claude Desktop ou un autre client MCP de créer une session checkout (`lomi_checkout`, `action=create`). Connectez-vous en OAuth ou avec une clé API. Voir [MCP pour clients IA](/build/mcp).

## 2. Payer avec un moyen de test

Pour un paiement carte réussi simple, utilisez :

| Champ | Valeur |
| --- | --- |
| Numéro de carte | `4242 4242 4242 4242` |
| Expiration | Une date future, par exemple `12/34` |
| CVC | Trois chiffres au choix |

Vous pouvez aussi tester le mobile money en sandbox. Consultez [paiements sandbox](/start/sandbox-payments) pour le comportement complet.

## 3. Vérifier le résultat

Après le paiement, vérifiez :

- Le checkout redirige vers votre URL de succès.
- La transaction apparaît dans la vue test du tableau de bord.
- Votre solde de test évolue si la méthode crée une transaction complétée.
- Votre endpoint webhook reçoit l’événement si les webhooks sont configurés.

Depuis le CLI :

```bash filename="Terminal"
lomi transactions list --json
```
