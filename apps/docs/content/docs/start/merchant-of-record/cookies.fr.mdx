title: 'Cookies'
description: 'Cookies utilisés par docs.lomi.africa.'
---

docs.lomi.africa utilise un petit jeu de cookies first-party. Il n’y a pas de pixel publicitaire sur ce site.

| Cookie | Rôle | Durée |
| --- | --- | --- |
| `lomi.language` | Mémoriser l’anglais ou le français | Environ 1 an |
| `lomi_docs_session` ou `__Host-lomi-docs-session` | Session Try-it après connexion tableau de bord | Session / quelques heures |
| `lomi_tryit_org` | Organisation choisie pour Try-it | Session |
| `lomi-theme` | Thème clair ou sombre | Local (stockage navigateur) |

L’éventuel bandeau cookies du site marketing est sur [lomi.africa](https://lomi.africa). L’authentification API n’utilise pas ces cookies docs : envoyez `X-API-KEY` depuis votre serveur.

Voir aussi [Confidentialité](/start/merchant-of-record/privacy).
