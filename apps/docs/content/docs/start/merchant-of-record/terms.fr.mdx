Utiliser l’API lomi., le tableau de bord, le serveur MCP ou la documentation implique d’accepter ces conditions. En particulier :

- Le sandbox (`lomi_sk_test_*`) sert au développement. Ne traitez pas de fonds réels avec des clés de test.
- Les clés live (`lomi_sk_live_*`) sont des secrets. Ne les embarquez pas dans une app client et ne les commitez pas.
- L’usage acceptable des paiements est décrit dans [Usage acceptable](/start/merchant-of-record/acceptable-use).
