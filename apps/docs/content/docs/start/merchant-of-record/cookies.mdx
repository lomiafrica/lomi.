docs.lomi.africa uses a small set of first-party cookies. There is no advertising pixel on this site.

| Cookie | Purpose | Duration |
| --- | --- | --- |
| `lomi.language` | Remember English or French | About 1 year |
| `lomi_docs_session` or `__Host-lomi-docs-session` | Docs Try-it session after dashboard handoff | Session / a few hours |
| `lomi_tryit_org` | Selected organization for Try-it | Session |
| `lomi-theme` | Light or dark theme | Local (browser storage) |

The marketing site cookie notice, when shown, lives on [lomi.africa](https://lomi.africa). API authentication does not use these docs cookies; send `X-API-KEY` from your server.

See also [Privacy](/start/merchant-of-record/privacy).
